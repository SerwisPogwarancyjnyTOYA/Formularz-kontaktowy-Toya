# Logotypy

Aplikacja nie generuje ani nie przerabia znaków marek. Wstaw tutaj oryginalne, wysokiej jakości pliki PNG/SVG:

- `toya.png`
- `yato.png`
- `vorel.png`
- `sthor.png`
- `lund.png`
- `flo.png`
- `fala.png`

Jeżeli plików nie ma w `assets/logos/`, strona spróbuje użyć plików z głównego katalogu repozytorium, np. `yato.png`.
