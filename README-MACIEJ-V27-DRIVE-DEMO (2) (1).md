# PGW Service Hub v27 — demo na Google Drive

Ta wersja poprawia start aplikacji pod prezentację:

- ekran startowy nie pokazuje już przypadkowych rekordów bez podglądu,
- przykłady startowe są wybierane z rekordów mających przypięty Google Drive ID,
- dodano mapowanie Drive dla `00610`, oprócz `YT-827795`, `YT-852371`, `YT-85177`,
- klient nadal może szukać po całej bazie części i rysunków,
- jeśli dla wyniku nie ma jeszcze Drive ID, strona pokazuje kontrolowany komunikat i link do wyszukania w Google Drive.
