# Publishing notes

Ta paczka jest gotowa jako pełne repo. Nie trzeba doklejać poprzednich patchy v68–v72.

## Nie wrzucać osobno

- starych paczek `pgw-v68-*`, `pgw-v69-*`, `pgw-v70-*`, `pgw-v71-*`,
- starego folderu `.git` z Drive,
- lokalnych backupów `_generated-backups`.

## Wrzucić całość

Wrzuć całą zawartość folderu `pgw-service-hub-publish-20260710-v73` do repo. Jeśli GitHub pokazuje dużo zmian w JSON-ach, to normalne — to pełny release publikacyjny.
