# Wersja kierownikowa 2

W tej wersji widok klientowski jest oczyszczony:

- brak banera „wersja poglądowa”,
- brak technicznych komunikatów o imporcie/Drive/GitHub,
- brak stanów magazynowych w widoku części,
- lista części działa nawet wtedy, gdy rysunek nie jest jeszcze aktywnie podpięty,
- nazwy robocze typu „nazwa urządzenia do uzupełnienia” są wygładzane w UI.

Pełne globalne podpięcie rysunków z Drive pozostaje następnym etapem.
