# QA checklist

- [ ] Strona ładuje się bez błędów w konsoli.
- [ ] `healthcheck.html` pokazuje OK przy kluczowych plikach.
- [ ] Wyszukiwanie po pełnym indeksie działa.
- [ ] Wyszukiwanie po indeksie bez myślnika działa.
- [ ] Rysunek PDF otwiera się w panelu i w nowej karcie.
- [ ] Część można dodać do koszyka.
- [ ] Tryb ręcznego opisu części działa, gdy brak listy pozycji.
- [ ] Dane kontaktowe przepuszczają email albo telefon.
- [ ] Mail końcowy ma adres `service@yato.pl`.
- [ ] Panel admina działa tylko z `?admin=1`.
- [ ] Release JSON i CSV dają się pobrać.
