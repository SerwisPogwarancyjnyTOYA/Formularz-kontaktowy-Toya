# Źródła danych

## Główne pliki

- `data/devices.json` — urządzenia.
- `data/drawings.json` — rysunki i powiązania.
- `data/parts.json` — części z bazy.
- `data/drive-drawings-map.full.json` — pełny manifest rysunków PDF z Drive.
- `data/drive-drawings-map.converted.json` — manifest PDF-ów po konwersji.

## Kontrola jakości PDF

- `data/pdf-device-overrides.json` — ręczne przypisania PDF do urządzeń.
- `data/pdf-orphans.json` — PDF-y bez rozpoznanego urządzenia.
- `data/pdf-quality-report.json` — raport jakości PDF.
- `data/pdf-override-candidates.json` — kandydaci do ręcznego przypisania.
- `data/deployment-state.json` — stan ostatniego generowania.
- `data/release-info.json` — opis aktualnego release.

## Ważne

Pliki z cenami i stanami magazynowymi nie są częścią strony klienta. Formularz nie pokazuje cen ani dostępności.
