# PGW v82 — UI translation foundation

Zakres tej wersji:

- tłumaczymy sam interfejs formularza: nagłówki, kroki, przyciski, komunikaty, podpowiedzi, walidację i panel PDF;
- nie tłumaczymy jeszcze nazw urządzeń, nazw części ani PDF-ów;
- wygenerowany mail do serwisu pozostaje po polsku, żeby obsługa otrzymała spójne zgłoszenie;
- pierwsza dopracowana para językowa: PL/EN.

Zasada jakości: żadnego masowego translatora dla części technicznych. Części i urządzenia dostaną osobny słownik serwisowy w następnym etapie.

Pliki dodane:

- `i18n.js` — lekka warstwa tłumaczeń UI bez ruszania danych technicznych;
- `data/i18n-ui-v82.json` — jawny słownik UI do przeglądu i korekty;
- `docs/UI_TRANSLATION_V82.md` — opis zakresu tłumaczeń.
