
# Phone-killer UX

Zmiany wdrożone w tej paczce:

- Komunikat na starcie: przez telefon nie dobieramy części.
- Wizard krokowy: klient widzi tylko aktualny etap.
- Pasek postępu: urządzenie → rysunek → zapytanie → dane → mail.
- Tryb „Nie znam modelu” dodaje czerwone przypomnienie o zdjęciach do podglądu i treści maila.
- Plan awaryjny dla `mailto:`: kopiowanie treści i ręczna wysyłka na service@yato.pl.
- Instrukcja obsługi rysunku na telefonie.
- Komunikacja czasu odpowiedzi: 2–4 godziny robocze.

GUS po NIP zostaje jako kolejny etap, bo wymaga backendu/proxy. Nie wkładamy integracji bezpośrednio w statyczny frontend.
