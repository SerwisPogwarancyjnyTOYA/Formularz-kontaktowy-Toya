
# Stopki mailowe — warianty

- `email-signature-maciej-universal-hosted.html` — wersja uniwersalna dla większości klientów poczty.
- `email-signature-maciej-outlook-hosted.html` — wersja zachowawcza dla Outlooka.
- `email-signature-maciej-gmail-hosted.html` — wersja uproszczona pod Gmail.

Ważne: logotypy są linkowane po publicznych URL-ach z GitHub Pages, dzięki czemu stopka nie zależy od lokalnych plików.
