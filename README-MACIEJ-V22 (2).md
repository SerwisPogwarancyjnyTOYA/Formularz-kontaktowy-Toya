# PGW Service Hub v22 — przywrócony formularz

Ta wersja przywraca prosty formularz z pierwszego `yato-service-hub-repo.zip`:
- Imię i nazwisko / firma
- E-mail
- Telefon
- NIP
- Dane do faktury
- Adres wysyłki
- Uwagi

Usunięte zostały przyciski typu „Generuj maila”, „Otwórz pocztę”, „Pobierz JSON”. Zostaje tylko treść do skopiowania i przycisk Kopiuj.

Dodatkowo pliki są zapisane podwójnie:
- `app.js` i `assets/app.js`
- `app.css`, `assets/app.css`, `assets/style.css`

Dzięki temu GitHub Pages nie powinien zostać na starej wersji przez pomyłkę ścieżek.
