# PGW Service Hub — baza rysunków kompletna

Czysta wersja produkcyjna. Każdy rysunek PDF z manifestu Drive jest bezpośrednio dostępny w bazie urządzeń.

## Zakres danych

- Rysunki w bazie: 1421
- Unikalne modele/urządzenia w bazie: 1410
- Unikalne pliki PDF z Drive: 1405
- Modele z listą części: 34
- Modele PDF-only / lista części do uzupełnienia: 1376

## Zasada działania

Jeśli urządzenie ma rysunek złożeniowy, ma być wyszukiwalne. Marka i pełna lista części są dodatkami, a nie warunkiem pokazania PDF.

Modele bez podpiętej listy części przechodzą trybem opisowym: klient widzi rysunek PDF i opisuje potrzebną pozycję w zapytaniu.
