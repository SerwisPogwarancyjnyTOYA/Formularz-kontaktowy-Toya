# Wdrożenie v58

1. Wypakuj paczkę.
2. Wrzuć zawartość do repozytorium GitHub Pages.
3. Nie wrzucaj PDF-ów do repo — zostają na Google Drive.
4. Po publikacji odśwież stronę z parametrem:

`?v=20260617-v58-clean-production`

## Kontrola przed publikacją

- Na stronie nie powinno być widocznych napisów typu `v53`, `v49`, `monitor bazy`, `marki do rozpoznania`.
- Przy modelu z PDF-em, ale bez listy części, strona powinna mówić o liście do uzupełnienia, nie o urządzeniu spoza bazy.
- Jeśli część ma ZUN albo jest składnikiem zestawu, informacja trafia do maila dla serwisu.
